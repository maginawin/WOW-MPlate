# 普通头顶姓名最小尺寸调节方案

日期：2026-11-10。状态：用户已确认实施，功能与离线验证已完成，待游戏内验收。

## 结论与证据

在现有 MPlate 设置面板增加独立的“头顶姓名最小尺寸”滑块，直接控制客户端参数 `WorldTextMinSize`。此项用于未选中单位、关闭友方玩家姓名板时的普通头顶姓名，与已有的“所有姓名板文字”分开。

- 用户截图确认“无限”客户端为 `1.60.1 / Build 70862 / Interface 16001`，参数初始读取为 `0.000000`；用户随后确认修改该参数实际有效。
- 公开 UI 源码的 `Blizzard_SettingsDefinitions_Frame/Accessibility.lua` 为此参数使用 `0～64`、步长 `2`。这只能证明源码定义；先前提供的游戏菜单路径未在用户客户端得到确认，本功能不依赖该菜单入口。
- 当前 `Options.lua` 已有通用滑块、单项重置、全部重置和面板打开刷新机制，可复用布局。
- 当前 `Core.lua` 修改姓名板 FontString，不控制普通世界姓名，因此需要接入 CVar；无需新增姓名绘制机制或修改姓名板显隐策略。
- 当前工作区为 `dev`，已有 `Core.lua`、`MPlate.toc`、`README.md` 未提交改动及未跟踪 `tests/`，实施时保留这些双端适配工作。

## 用户可见行为

| 项目 | 决定 |
| --- | --- |
| 位置 | `/mplate` 面板中，放在“所有姓名板文字”之后 |
| 英文标题 | Minimum Overhead Name Size |
| 简体中文标题 | 头顶姓名最小尺寸 |
| 范围 | 0～64，步长 2 |
| 说明 | 调整普通头顶姓名的最小显示尺寸；无需开启姓名板。全局生效，不能只调整友方玩家。 |
| 0 的说明 | 不额外限制最小尺寸，避免误解为隐藏姓名 |
| 修改 | 用户拖动后直接写入游戏参数，实时生效 |
| 首次打开 | 显示当前游戏值，保留用户先前通过命令或其他设置修改的值 |
| 单项重置 | 读取客户端提供的参数默认值，再写回；不将当前值或启动时的值误当默认值 |
| 全部重置 | 同时恢复此参数的客户端默认值；操作范围包含这项全局设置 |
| 不支持的客户端 | 参数缺失或非有效数值时不创建该滑块，现有设置继续工作 |

该功能不启用友方姓名板，不调整选中状态，不要求显示血条。这里的“最小尺寸”不等同于在所有距离下固定字号。

## 配置与同步

采用游戏 CVar 作为唯一数据来源，由客户端负责持久化。不新增 `MPlateDB` 字段，不在登录时反复覆盖参数，不保存启动前快照或引入恢复状态机。现有 SavedVariables 机制适合插件自行维护的字体和布局覆盖值；本项已经有可读写的原生参数，另存副本会增加来源冲突和迁移成本。

1. 打开面板时读取当前参数；安装插件和打开面板均不写入。
2. 使用现有面板显隐流程，在下次打开时反映游戏命令或其他插件修改的值。本阶段不新增持续监听或轮询。
3. 必须保护程序性滑块刷新：现有 `CreateSliderRow` 和 `RefreshOptionsSliders` 使用 `SetValue`，它可能触发 `OnValueChanged`。新增项的初始化、重新打开、重置后显示刷新均不得意外写回或反复量化参数。
4. 若外部值不是步长 2 的整数，打开面板仍保留并显示实际读数；滑块位置可以受范围限制，只有用户主动拖动时才按本滑块步长写入。
5. 默认值通过客户端 API 获取；不可读时禁用该项重置，不盲目写死 `0`。全部重置继续处理其他可用项，并明确提示此项未重置。
6. 写入需要处理 API 失败并回读确认。失败时恢复实际值的显示并给出简短提示，不把失败显示为成功，不加入后台自动重试。

- 参数存在：当前值为 0、20、32 以及外部非步长值时，初次加载和打开面板都不产生写入。
- 主动拖动：正确量化并写入，回读显示一致；缺失、非法参数值和写入异常不影响现有面板。
- 单项/全部重置：使用客户端默认值，程序性刷新不重复写入；默认值缺失和写入失败时不虚报成功。
